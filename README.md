# The House in the Rain

A small, mysterious text adventure built with Python as a learning project.
Explore an old house, search for clues, collect items, and find a way to unlock
the front door.

## Run

Requires Python 3. No external packages needed.

```sh
git clone https://github.com/maxbelich/minitextgame-python.git
cd minitextgame-python
python3 main.py
```

## Play

Type `help` to see all commands. Start with `look around`, move between rooms
with commands like `go kitchen`, and check your bag with `inventory`.
Type `quit` to leave the game.
